# Internal docs (repo-only)

Material in this directory is **not part of the published documentation site**.
The site is built by mdBook from `docs/` only (`book.toml`), so anything that
should not appear publicly lives here instead.

- `AGENT.md` — context for AI coding agents working on components.
- `design/` — early design notes, kept for history.
- `planning/` — local analysis/planning notes (also gitignored; may be absent
  in a fresh clone).

See [`docs/index.md`](../docs/index.md) for the public documentation hub.
