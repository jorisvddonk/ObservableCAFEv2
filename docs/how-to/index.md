# How-to guides

Goal-oriented recipes for real tasks. Pick the one that matches what you're
trying to do; each assumes the stack from [Getting
started](../tutorials/getting-started.md) is available.

| Task | Guide |
|---|---|
| Start or stop all services | [Run the stack](run-the-stack.md) |
| Talk to the bus from a shell | [Use the cafe-cli](use-the-cli.md) |
| Give an AI assistant (opencode, Claude) access to the bus | [Connect via MCP](connect-mcp.md) |
| Store and stream binary assets (audio, images, files) | [Work with binary assets](use-binary-assets.md) |
| Give the LLM retrieval over your documents | [Set up the knowledge base](use-knowledgebase.md) |
| Verify the whole stack works | [Write and run E2E tests](write-e2e-tests.md) |
| Connect to the bus from another machine | [Connect over iroh](connect-over-iroh.md) |
| Add a brand-new service to the stack | [Add a service](add-a-service.md) |
| Debug a JS agent (logs, error chunks, hot-reload) | [Debug a JS agent](debug-js-agent.md) |

Looking for exact field names or message shapes instead? See the
[Reference](../reference/).
